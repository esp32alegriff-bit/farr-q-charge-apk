# FARRUSCO EV meter (ESP32-S3) project

Start here. This folder is the single place where the meter project is written down.

- `STATUS.md` — what has happened, newest first. Read this first.
- `hardware.md` — the board, its MAC address and what is connected.
- `firmware-plan.md` — what the firmware must do (agreed with the owner).
- `../docs/meter-contract.md` — the data contract every device follows (the source of truth for fields).
- `../AGENTS.md` and `../HANDOVER.md` — the rules for AI tools and the wider system.

Firmware source code lives on the owner's laptop, not in this repo, until the owner says otherwise.
Nothing is flashed to a board without the owner's approval.
